🗄️ Fix 2: Database Table Issues (500 Internal Server Error)

FIXED

Problem: AttendanceRecap model was trying to access a non-existent attendance_recaps table, causing 500 errors.

Solution: Created the missing table with proper schema:

Schema::create('attendance_recaps', function (Blueprint $table) { $table->id(); $table->unsignedBigInteger('user_id'); $table->integer('year'); $table->integer('month'); $table->integer('total_working_days'); $table->integer('present_days'); $table->integer('late_days'); $table->integer('absent_days'); $table->decimal('attendance_percentage', 5, 2); $table->integer('total_work_minutes'); $table->integer('ranking')->nullable(); $table->timestamps(); // Indexes and constraints $table->index(['user_id', 'year', 'month']); $table->foreign('user_id')->references('id')->on('users'); $table->unique(['user_id', 'year', 'month']); });
